# Гучність з навушників

Android-застосунок, який дає керувати гучністю кнопками навушників:

За замовчуванням (перемикач «Поміняти функції місцями» увімкнено):

| Дія | Результат |
|---|---|
| **Коротко натиснути ⏭** «Наступний трек» | гучність **+1 крок** |
| **Коротко натиснути ⏮** «Попередній трек» | гучність **−1 крок**, аж до 0 |
| Затиснути ⏭ | трек вперед |
| Затиснути ⏮ | трек назад |

Якщо вимкнути «Поміняти функції місцями»:

| Дія | Результат |
|---|---|
| Коротко натиснути ⏭ / ⏮ | трек вперед / назад (як завжди) |
| Затиснути ⏭ | гучність плавно **збільшується**, поки тримаєте |
| Затиснути ⏮ | гучність плавно **зменшується**, аж до 0 |

Працює з будь-яким плеєром (Spotify, YouTube Music, VLC…), у фоні й при вимкненому екрані.
Без інтернету, без реклами, нічого не збирає.

---

## 1. Готовий APK

Після збірки файл лежить тут:

```
app\build\outputs\apk\debug\app-debug.apk
```

## 2. Як зібрати APK

### Варіант А: Android Studio (найпростіше)

1. Відкрийте Android Studio → **Open** → виберіть папку `Навушники`.
2. Зачекайте, поки закінчиться синхронізація Gradle (рядок унизу).
3. Меню **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
4. Коли з'явиться сповіщення «APK(s) generated», натисніть **locate**: відкриється папка з `app-debug.apk`.

### Варіант Б: командний рядок Windows (PowerShell)

Потрібні JDK 17+ і Android SDK (ставляться разом з Android Studio).

```powershell
cd "$env:USERPROFILE\Проєкти\Навушники"
.\gradlew.bat assembleDebug
```

Запуск unit-тестів:

```powershell
.\gradlew.bat testDebugUnitTest
```

### Якщо збірка падає на Windows

Папка проєкту має кириличну назву, а Windows із не кириличною мовою системи (наприклад, французькою)
передає такі шляхи в Java некоректно. Що вже зроблено в проєкті:

* `gradlew.bat` запускається через коротке латинське ім'я папки (8.3), тому помилки
  `Could not find or load main class org.gradle.wrapper.GradleWrapperMain` більше немає;
* у `gradle.properties` додано `android.overridePathCheck=true`.

Можливі проблеми й рішення:

* **`Unable to establish loopback connection`**: перед збіркою виконайте
  ```powershell
  $env:GRADLE_OPTS = "-Djdk.net.unixdomain.tmpdir=$env:USERPROFILE\.gradle"
  $env:JAVA_TOOL_OPTIONS = $env:GRADLE_OPTS
  ```
* **Тести падають з `ClassNotFoundException`** (APK при цьому збирається нормально): запустіть їх
  з тимчасового латинського диска:
  ```powershell
  subst N: "$env:USERPROFILE\Проєкти\Навушники"
  N:
  .\gradlew.bat testDebugUnitTest
  C:
  subst N: /D
  ```
* Найнадійніше рішення: перенести проєкт у папку з латинською назвою, наприклад `C:\Projects\HeadphonesVolume`.

## 3. Як встановити на телефон

### Через USB-кабель (adb)

1. На телефоні: **Налаштування → Про телефон** → 7 разів натисніть «Номер збірки», щоб увімкнути режим розробника.
2. **Налаштування → Для розробників** → увімкніть **«Налагодження через USB»**.
3. Підключіть телефон кабелем і погодьтеся на запит «Дозволити налагодження USB».
4. На комп'ютері:
   ```powershell
   & "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe" install -r app\build\outputs\apk\debug\app-debug.apk
   ```

### Копіюванням файлу

1. Скопіюйте `app-debug.apk` на телефон (кабелем, через Telegram «Збережене», Google Диск тощо).
2. Відкрийте файл на телефоні. Якщо Android попросить, дозвольте **«Встановлювати невідомі застосунки»**
   для того застосунку, з якого відкриваєте (Файли, Telegram…).
3. Натисніть **Встановити**. Якщо Play Захист покаже попередження, натисніть «Усе одно встановити»
   (застосунок не підписаний у Play Маркеті, це нормально для власної збірки).

## 4. Як надати дозволи

Відкрийте застосунок: на екрані є покрокова інструкція з кнопками. Статус кожного кроку (✅ / ❌)
оновлюється, коли ви повертаєтеся в застосунок.

1. **Спеціальні можливості.** Кнопка відкриває налаштування. Знайдіть «Гучність з навушників»
   (іноді в розділі «Завантажені застосунки» або «Встановлені служби») і ввімкніть.

   **Android 13 і новіші: «Обмежене налаштування».** Для застосунків не з Play Маркету перемикач
   спершу заблокований. Тоді:
   1. спробуйте його ввімкнути (з'явиться вікно «Обмежене налаштування»), натисніть «OK»;
   2. у застосунку натисніть «Відкрити «Про застосунок»» (або Налаштування → Застосунки → Гучність з навушників);
   3. натисніть **⋮** у верхньому правому куті → **«Дозволити обмежені налаштування»** і підтвердьте;
   4. поверніться до кроку 1: тепер перемикач активний.

2. **Доступ до сповіщень.** Потрібен, щоб коротке натискання перемикало трек саме у вашому плеєрі.
   Вміст сповіщень застосунок не читає.

3. **Не обмежувати роботу у фоні.** Щоб Android не вимикав застосунок. Додатково:
   * **Xiaomi / Redmi / POCO:** Безпека → Дозволи → **Автозапуск** → увімкнути; і в налаштуваннях
     застосунку: Контроль активності → «Без обмежень».
   * **Samsung:** Налаштування → Застосунки → Гучність з навушників → Батарея → **«Без обмежень»**.
   * **Huawei / Honor:** Батарея → **Запуск застосунків** → вимкнути «Автоматично» → увімкнути всі три перемикачі.

## 5. Перевірка: кнопка «Тест»

У розділі «Перевірка кнопок» натисніть **«Тест»** і понатискайте кнопки навушників. У журналі видно:

* яку кнопку отримав телефон (⏭, ⏮, ⏯, 🔊…), коли її натиснули й відпустили;
* звідки прийшла подія («Спец. можливості» або «Режим сумісності BT») і назву пристрою;
* що розпізнав застосунок: коротке чи довге натискання і поточну гучність.

У режимі тесту трек **не перемикається**, а гучність **змінюється**. Тест сам вимикається,
коли ви виходите з застосунку.

## 6. Якщо кнопки Bluetooth-навушників не ловляться

Це не помилка застосунку, а особливість Android:

* **Дротові навушники** надсилають кнопки як звичайні натискання, тож їх стабільно бачать Спеціальні можливості.
* **Bluetooth-навушники** (AVRCP) на багатьох телефонах передають кнопки **напряму** в медіасесію
  плеєра, оминаючи Спеціальні можливості.

Що робити:

1. Увімкніть «Тест» і натисніть кнопки на Bluetooth-навушниках.
2. Якщо **нічого не з'являється**, увімкніть **«Режим сумісності (експериментальний)»** у розділі
   «Bluetooth-навушники» (потрібен доступ до сповіщень, крок 2). Застосунок тихо «грає» тишу і тримає
   власну медіасесію, тому Android надсилає кнопки йому. Коротке натискання, пауза та інші кнопки
   пересилаються вашому плеєру. У шторці буде постійне сповіщення.
3. Повторіть тест: події мають з'явитися з позначкою «Режим сумісності BT».

Відомі обмеження режиму сумісності:

* Він експериментальний: на деяких прошивках Android усе одно віддає кнопки плеєру.
  Якщо плеєр перезапускає відтворення, застосунок намагається знову перехопити кнопки, але не завжди встигає.
* Режим вмикається сам, щойно підключаються навушники (Bluetooth або дротові), і вимикається після їх
  відключення. Тишу застосунок відтворює лише поки навушники підключено. Сповіщення в шторці показує стан:
  «Навушники підключено: кнопки працюють» або «Чекаю на навушники».
* Після перезавантаження телефона режим запускається сам. Якщо Android не дозволив запуск одразу,
  він запуститься під час підключення навушників або ввімкнення екрана. Щоб Android не вимикав застосунок,
  виконайте крок 3 (робота у фоні) і на Xiaomi/POCO увімкніть «Автозапуск».
* На екрані навушників або в машині може не показуватися назва треку.

### Навушники самі змінюють гучність при затисканні

Якщо під час затискання журнал «Тесту» порожній, а на екрані рухається шкала гучності, кнопка
телефону взагалі не надходить: навушники змінюють гучність самі. Для таких навушників є перемикач
**«Затискання навушників перемикає трек (експериментально)»** (видно, коли увімкнено «Поміняти функції місцями»).
Застосунок помічає зміну гучності, яку зробив не він і не кнопки телефону, повертає гучність назад
і перемикає трек: гучніше означає вперед, тихіше — назад. За одне затискання трек перемикається один раз.

Обмеження:

* За замовчуванням працює **лише при вимкненому екрані**. При увімкненому екрані працює, якщо увімкнено
  **«Також при увімкненому екрані»** (за замовчуванням вимкнено) і крок 1
  (Спеціальні можливості). Застосунок помічає дотики до екрана через невидиму точку розміром 1 піксель
  і протягом **4 секунд після дотику** вважає зміну гучності вашою (наприклад, повзунком), тож трек не перемикається.
  Тому якщо затиснути навушник одразу після дотику до екрана, гучність просто зміниться; зачекайте кілька секунд.
* На мить гучність може стати трохи вищою або нижчою, поки застосунок її не поверне.
* Кнопки гучності на самому телефоні при вимкненому екрані Android може не показувати застосунку.
  Якщо натискання кнопки гучності телефону при вимкненому екрані перемикає трек, вимкніть цей перемикач.

Якщо тест показує **лише одну подію** при довгому утриманні (одразу «натиснуто» і «відпущено»), це
навушники самі обробляють утримання (часто воно викликає голосового асистента або змінює гучність)
і не повідомляють телефону, що кнопку тримають. Довге натискання на таких навушниках розпізнати неможливо.
Іноді це можна змінити в фірмовому застосунку навушників (Galaxy Wearable, Sony Headphones, Soundcore тощо).

## 7. Налаштування

| Параметр | Значення | Що робить |
|---|---|---|
| Увімкнено / Вимкнено | — | вимкнено: кнопки працюють як звичайно |
| Поміняти функції місцями | типово увімкнено | увімкнено: коротке = гучність, затискання = трек; вимкнено: навпаки |
| Час довгого натискання | 250–1000 мс (типово 400) | скільки тримати, щоб спрацювало затискання |
| Швидкість зміни гучності | 80–400 мс на крок (типово 150) | лише для режиму «затискання = гучність»; менше = швидше |
| Поміняти кнопки місцями | — | вперед = тихіше, назад = гучніше |
| Вібрація при кожному кроці | — | коротка вібрація на кожен крок гучності |
| Показувати системну шкалу | — | показує стандартний повзунок гучності Android |

Налаштування зберігаються і діють одразу, без перезапуску.

### Тихіше за найменшу гучність (рівень «½»)

Спершу задайте **«Найменша чутна гучність»**: на шкалі з 30 кроків (наприклад, Xiaomi/POCO з
Bluetooth-навушниками) крок 1 часто звучить як тиша, тому там за замовчуванням 2. Нижчі рівні застосунок
пропускає: вгору з 0 одразу на цю гучність, вниз з неї в ½ або в 0.

Якщо навіть найменша чутна гучність загучна, увімкніть «Рівень «½» нижче найменшої чутної гучності»
(типово увімкнено). Тоді кроки «тихіше» йдуть так: … → 3 → 2 → **½** → 0, а «гучніше» з ½ повертає на 2.
На рівні ½ системна гучність лишається 2, а застосунок додатково приглушує весь звук телефону
глобальним аудіоефектом. Повзунок «Наскільки тихіше» задає силу приглушення: 3–20 дБ, типово 10 дБ
(приблизно вдвічі тихіше на слух).

* Рівень ½ знімається сам, якщо змінити гучність кнопками телефону чи повзунком, або відключити навушники.
* На екрані застосунку є кнопки «− Тихіше» і «+ Гучніше»: ними можна перевірити рівень ½ без навушників.
* Глобальні аудіоефекти підтримують не всі телефони. Якщо не вийде, застосунок покаже попередження,
  і з 1 гучність одразу йтиме в 0. Іноді допомагає вимкнути інші звукові ефекти (Dolby, еквалайзер).

Якщо телефон показує попередження «Висока гучність може пошкодити слух», збільшення зупиниться:
підтвердьте попередження на екрані, і далі гучність знову змінюватиметься.

## 8. Будова коду

```
app/src/main/java/com/headphones/volume/
├─ core/PressDetector.kt      логіка короткого/довгого натискання (без Android, покрита тестами)
├─ core/KeyRouter.kt          приймає кнопки з усіх джерел і виконує дії
├─ core/Diagnostics.kt        стан сервісів і журнал «Тесту»
├─ core/Permissions.kt        перевірка дозволів
├─ audio/VolumeController.kt  зміна гучності (AudioManager, STREAM_MUSIC)
├─ audio/PlayerController.kt  команди активному плеєру (MediaController)
├─ service/HeadsetAccessibilityService.kt  перехоплення кнопок (Спеціальні можливості)
├─ service/MediaNotificationListener.kt    дозвіл бачити активні плеєри
├─ service/BluetoothCompatService.kt       режим сумісності для Bluetooth
├─ settings/SettingsRepository.kt          налаштування (DataStore)
└─ ui/SettingsScreen.kt       екран налаштувань (Jetpack Compose)
├─ core/EarbudVolumeDetector.kt  розпізнає зміну гучності навушниками як перемикання треку
app/src/test/.../PressDetectorTest.kt         19 unit-тестів логіки натискань
app/src/test/.../EarbudVolumeDetectorTest.kt  10 unit-тестів розпізнавання гучності навушників
```

Мінімальна версія: Android 8.0 (API 26). Дозволу INTERNET у застосунку немає.
